Drop your screenshots of the workstation here, named after the tour step they
illustrate:

    garage.png overview.png live.png faults.png service.png
    firmware.png maps.png sessions.png

How to capture (no extra software):
  1. Run the workstation (python3 run_server.py) and open it in your browser.
  2. Select a bike in the simulator (Guzzi: Griso 1200 8V / 2012 works well),
     connect, and walk the view you want to show.
  3. Screenshot the browser window (PrtScn / Cmd+Shift+4) and save the PNG here
     under the matching name. Full-window captures look best; keep the browser
     window a consistent size across shots.

Any file that is missing simply shows its labelled placeholder on the Tour
page (web/tour.html) -- nothing breaks.

Affiliate links: edit web/tour.html and search for "a.affiliate"; replace each
href with your Amazon affiliate link (the ?tag=YOURTAG-20 placeholders are
easy to find).
