# Review of supplied motorcycle tuning and diagnostic sources

Reviewed 2026-10-29. Linked claims are those of the source; the GuzziOnBoard
integration is not necessarily hardware-tested. Sources are pinned where
possible. GPL reuse retains attribution and license terms; contributing changes
upstream is not required. Third-party firmware, customer files, commercial
assets and authentication captures are not bundled.

| Source | Finding and use in this project |
| --- | --- |
| [diy-afr-tuning `398d5684`](https://github.com/jooptoorn/diy-afr-tuning/tree/398d5684b79b23030019102a413cfb54e68fc89c) | GPL-3.0; Rotax V990 wideband, RPM and TPS logging and Power Commander workflow. Our existing offline log analysis accepts explicit measured/target AFR, timing, sensor delay, settling and bounded corrections. No hardware/logger code copied. |
| [Performance-Harley-Davidson-Tuning `a3250e46`](https://github.com/aaronlumen/Performance-Harley-Davidson-Tuning/tree/a3250e460e1781b8f594e1b400e5a05058d23534) | GPL repository of Technoresearch `.ori` dyno tunes; files can contain customer data and are not generic map definitions. Not bundled. See `HARLEY_TUNING.md`. |
| [rusEFI `5359cc9`](https://github.com/rusefi/rusefi/tree/5359cc971b60a9a0ee3f0f2a870dbb64f0ad36ef) | Open-source aftermarket ECU with Harley engine configuration; not stock Delphi. Root license states GPL-3.0 and extra usage terms. Independently implemented bounded, synthetic-tested serial reads; no source or tunes copied. See `RUSEFI_AND_POWERVISION_RESEARCH.md`. |
| [rusEFI snapshot build server](https://rusefi.com/build_server/) | Board-specific snapshots and bundles, not factory Harley firmware. The desktop can locally extract a signature from a selected INI and generate a user-clicked lookup link; no bundle, firmware or program is automatically downloaded or installed. See `RUSEFI_AND_POWERVISION_RESEARCH.md`. |
| [Power Vision security research](https://therealunicornsecurity.github.io/Powervision-2/) | Reverse engineering of the tuner's USB file service, not the bike ECU. Example passwords/keys explicitly fake; article has a checksum description discrepancy. No code, credentials, or exploits copied. |
| [Power Vision research, part 3](https://therealunicornsecurity.github.io/Powervision-3/) | PV1 tuner modification and licensing research, not a stock ECU protocol. Author warns the proof of concept can damage the ECU and brick the tuner. `pvinfo` via the proprietary DLL is a future device-integration lead; no patched firmware, identifiers, DLL calls or bypasses added. See `RUSEFI_AND_POWERVISION_RESEARCH.md`. |
| [Honda-Motorcycle-ECU-Tools `84c20373`](https://github.com/sophienyaa/Honda-Motorcycle-ECU-Tools/tree/84c203736dcea4ef1b436bfc4d36eca73d897110) | MIT, copyright Mick Wheeler. CRF250L source reports table 11; adapted into the offline response decoder, with MIT license included. Source uses integer arithmetic truncation; UI displays fractional interpretation, explicitly marked. Its documented table 11 capture starts with `13` and fails its own negative-sum checksum; we do not silently correct it. This CRF250L source remains offline only; the separate CBR600RR 2005 source has a read-only live integration. |
| [HayabusaGen3 `58de6d21`](https://github.com/DanCycles/HayabusaGen3/tree/58de6d211b6f42b254a1f37de13f4802487b2ba5) | MIT repository describes 2022+ Gen 3, provides a 2 MiB sample and XDF `32910-10LX0`. XDF contains `xdf moto bin files` branding and password metadata; third-party asset rights are not clear from the repo license, so neither XDF nor ROM is redistributed. User-supplied definitions can be inspected locally; absence of an XDF checksum does not prove no checksum is needed. README's flash tutorials are not present as an actionable implementation. |
| [Yamaha-DataLogger `d06a80ae`](https://github.com/terrafirma2021/Yamaha-DataLogger/tree/d06a80aef95bf97d6e15eef1c1d851fde6cc4975) | Yamaha K-Line to ELM/BLE/OBD emulator, RPM, speed and temperature. No repository license found; no code copied and no model-independent live protocol assumed. |
| [motolink `7879a856`](https://github.com/fpoussin/motolink/tree/7879a8567dd43d467506aa8c613f310f0deb2fdb) | GPL-3.0 hardware and fuel-mapper project; wideband/manual correction workflow complements our existing offline log analysis. No generic factory ECU flashing path taken from it. |
| [HondaECU-1 `b59ae98b`](https://github.com/aeaphichart/HondaECU-1/tree/b59ae98baf092def23d7c34d5ef5f43bd6aba952) | GPL-3.0 Honda K-Line diagnostics, flashing research, XDFs and checksum table. Nine XDFs are research-only; a separately adapted MGZ-A03 XDF and scoped offline checksum build are integrated. `XDF_LIBRARY.md` documents the source byte-order mismatch and exact locks. |
| [LibreTune `981a8996`](https://github.com/RallyPat/LibreTune/tree/981a89964f5a22c99d857f8861c59906af3772bc) | GPL-2.0-only, for aftermarket INI-based ECUs. Good examples of delay and transient filters, but its GPL-2-only code was not combined with this AGPL-3 project; repository itself warns it is early-stage. Existing GuzziOnBoard log analysis already provides fixed-delay and dwell filtering. |
| [HyperTuner `7170490e`](https://github.com/hyper-tuner/hypertuner/tree/7170490e043cb7b2a17408f0878f992a7e2df03f) | GPL-3.0 project roadmap; README says development is private pending alpha. No usable tuning code imported. |
| [c3Tuner `7dfd9814`](https://github.com/deanh8/c3Tuner/tree/7dfd98146ec08cabf353fbfeb266ef9319932f89) | MIT Dynojet C3 scripts for Harley, Honda, Indian and Yamaha. Wideband ratio and trim workflow depends on Dynojet host APIs and operator-defined targets; no tune values or code copied. Our log analyzer already implements a bounded measured/target fuel proposal. |
| [romHEX14-community `389fa1a1`](https://github.com/ctabuyo/romHEX14-community/tree/389fa1a1a40c071dfe06de996b655ff4d6bef2cb) | README claims GPL-3.0-or-later but repository has no root license file; includes numerous DLLs with separate provenance. A2L and checksum features are general, not an identified Harley calibration algorithm. No DLLs or code imported. |
| [BusaECUeditor `0a6088e1`](https://github.com/mkorkalo/BusaECUeditor/tree/0a6088e128c1887bb014619a1179b83d26cd3e61) | Older Suzuki ECU editor with no detected license; no code or bundled executables imported. Its existence does not establish Gen 3 flashing compatibility. |
| [OldSkullTuning bike XDF list](https://oldskulltuning.com/bin-definition-file-xdf-for-bike/) | Commercial definition catalog; vendor asks customers for their original file and technical details to supply a matching XDF. Link for discovery; assets not redistributed. |
| [MotoBinFiles XDF](https://motobinfiles.com/xdf/) | Definition preview and online identification service, not a freely licensed generic XDF. Do not upload a user image without explicit user action and consent. |
| [Motorcycle Tuning XDF Wiki](https://motoxdf.fandom.com/wiki/Special:AllPages) | Community wiki identifies numerous Ducati and Guzzi variants and includes inline XDFs; page states CC-BY-SA unless otherwise noted. Existing GuzziDiag XDF library already includes many related definitions. No additional wiki text or XDF copied. |
| [CBR250RR definition `8be351c7`](https://github.com/kelvinvalencio/cbr250rr-ecu-binary-definition/tree/8be351c718205843c842c7abe62eafa51bdac218) | Source lists N04 and ND1 release XDFs, explicitly warns to assume nothing is reliable and asks for testing/conversion-factor feedback. No license found, so no files copied. |
| [ECU Performance full XDF list](https://www.ecu-performance.com/ep/2000/01/01/full-xdf-list/) | Vendor lists software/part-number-specific definitions across many makes, including Harley and Honda. A listing is not a downloadable definition or a checksum algorithm. Link for research; no catalog material copied. |

The source review does not establish universal fitment, replace physical ECU
identification, or authorize flashing. All tuning proposals require independent
review. Do not operate diagnostic or tuning controls while riding.
